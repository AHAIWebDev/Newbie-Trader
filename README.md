# Stock Trader — Educational AI-Assisted Trading App

A hobby project for learning stock trading, technical analysis, and AI-assisted decision-making.

## ⚠️ Disclaimer
This application is for educational purposes only. It does not constitute financial advice.
Paper trading only until explicitly configured otherwise.

## Stack
- Backend: Node.js + Express
- Frontend: React + Vite + TailwindCSS (Phase 2)
- Database: PostgreSQL + Prisma (Phase 3)
- AI: Anthropic Claude API
- Market Data: Polygon.io
